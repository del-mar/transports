<h1>Transport Budget Calculator</h1>

This is a simple web application designed to help users estimate transportation costs based on specific variables. The tool provides a quick and easy way to calculate pricing for transport services.
<h2>Features: </h2>
<p>Estimate transport costs based on service duration and distance.</p>
<p>User-friendly interface for quick calculations.</p>
Dynamic price adjustments based on predefined pricing structure.
<h3>Live Demo</h3>

Check out the live version of the project here: Transport Budget Calculator

Pricing Structure

The application calculates transport costs using the following pricing structure:

Service Duration:

1 hour: 40€

2 hours: 60€

3 hours: 87€

4 hours: 112€

Additional Distance Charges:

Up to 30 km: No additional charge

30 - 80 km: 0.30€/km

80 - 150 km: 0.40€/km

150 - 200 km: 0.45€/km

Technologies Used

HTML - Structure of the application

CSS - Styling and layout

JavaScript - Logic for calculations and interactions

How to Use

Enter the required details such as service duration and distance.

Click on the calculate button to get the estimated cost.

Adjust inputs as needed to explore different pricing scenarios.
